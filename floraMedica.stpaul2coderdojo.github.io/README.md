## 🚀 GitHub Pages Deployment Guide

This repository is designed for instant zero-configuration deployment to **GitHub Pages**:

1. **Create Repository:**
   Create a new public GitHub repository named:
   `floraMedica.stpaul2coderdojo.github.io` under organization/user `stpaul2coderdojo`.

2. **Push Files:**
   Push the contents of this folder (`index.html`, `CNAME`, `robots.txt`, `sitemap.xml`, `README.md`) to the `main` branch.

3. **Enable GitHub Pages:**
   - Go to **Settings** > **Pages**
   - Source: **Deploy from a branch**
   - Branch: `main` / `(root)`
   - Click **Save**.

4. **Custom Domain:**
   Ensure `floraMedica.stpaul2coderdojo.github.io` is listed under Custom domain (enforced by the included `CNAME` file). Check **Enforce HTTPS**.
